# 05 · UI (owner: D)

Streamlit, `ui/app.py`, run with `streamlit run ui/app.py`. It imports `boomerang` directly (no API). Build it against `fixtures/` from minute one; swap to the real pipeline at checkpoint 2.

## 1. Layout

**Sidebar**
- Logo + "Boomerang: two-way AI cloud migration"
- Source: `sample-app/aws` (default) · `sample-app/local` · custom path (stretch S5)
- Action buttons: **Scan** · **Migrate →** (target auto = opposite platform) · **Round trip 🪃**
- Mode: `Live` / `Replay recorded run` (dropdown of `runs/` and `runs/golden/`)
- LLM mode badge (`live`/`record`/`replay` from settings) and model name

**Main area: tabs**

| Tab | Shows |
|---|---|
| **1 Scan** | App name + platform; **lock-in gauge** (0–100, big number, colored); components table (id, kind, provider, #usages, notes); **dependency graph** (`st.graphviz_chart` with a DOT string: files → components, colored by provider); env vars |
| **2 Plan** | AI summary; steps as cards: `DynamoDB → Postgres` · strategy badge (config/rewrite) · risk badge (low/med/high) · notes; warnings box; lock-in before → after |
| **3 Migrate** | Live event feed (`st.status` per stage); per-file diff viewer (`st.code(diff, language="diff")`, file selector); generated infra files (tabs: compose / schema.sql / main.tf / .env) |
| **4 Validate** | One row per attempt: ✅/❌ with passed/total; failing tests expandable (message + traceback); fixer diagnosis and fix diffs between attempts. This is where the demo's "AI fixes itself" moment is. |
| **5 Round trip** | Three columns: **Original (AWS)** → **Local** → **Back on AWS**. Each: platform icon, lock-in score, tests `7/7 ✅`, duration. Below: "diff between original and round-tripped code" size, plus a link to each leg's report |
| **6 Report** | Rendered `report.md` + download button |

## 2. Live progress

```python
def ui_sink(event: Event):
    st.session_state.events.append(event)
    placeholder.markdown(render_feed(st.session_state.events[-12:]))
```
Pass `emit_extra=ui_sink` to `pipeline.migrate()` / `roundtrip()`. Streamlit runs the call in the script thread; updating a placeholder from the sink works for this. Keep the last result in `st.session_state` so tab switches don't re-run anything.

## 3. Replay mode

Read a run directory: `run.json`, `plan.json`, `source.pam.json`, `events.jsonl`, `diffs/`, `validation/`. Animate the feed by re-emitting events with their original relative timing **compressed** (e.g. ×8) via `time.sleep`. Same rendering code as live, so this is cheap to build and it is the demo fallback.
