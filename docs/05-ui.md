## Live progress
Pipeline gets `emit_extra=ui_sink`; the sink appends to `st.session_state.events` and refreshes a feed placeholder. Keep results in `session_state` so tab switches don't re-run.

## Replay
Read a run directory and re-emit `events.jsonl` with compressed timing (×8). Same renderers as live. Works offline.
